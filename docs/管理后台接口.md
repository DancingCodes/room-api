# 星闪管理后台接口

## 配置与鉴权

服务端必须配置以下环境变量：

```dotenv
ADMIN_USERNAME=admin
ADMIN_PASSWORD=请使用强密码
```

管理员令牌与普通用户令牌相互隔离。除登录外，全部接口要求：

```txt
Authorization: Bearer admin_jwt_token
```

接口前缀：`/api/v1/admin`。响应格式沿用公共 API 的 `code`、`message`、`data`。

## 登录

`POST /api/v1/admin/auth/login`

```json
{
  "username": "admin",
  "password": "strong-password"
}
```

成功时返回 `token`，有效期 24 小时。

## 概览

`GET /api/v1/admin/dashboard`

返回当前房间数、房间内总人数、当前发布版本和最近创建的 5 个房间。

## 当前房间

- `GET /api/v1/admin/rooms?page=1&page_size=20`
- `GET /api/v1/admin/rooms/{room_id}`

房间模块只读。列表包含创建者昵称和邮箱、当前人数、上限、创建与最后变动时间；详情额外返回成员及其麦克风状态。

## App 版本

- `GET /api/v1/admin/app-versions`
- `POST /api/v1/admin/app-versions`
- `PUT /api/v1/admin/app-versions/{id}`
- `POST /api/v1/admin/app-versions/{id}/publish`
- `POST /api/v1/admin/app-versions/{id}/unpublish`

创建和编辑请求体：

```json
{
  "version_code": 2,
  "apk_url": "https://cdn.moonc.love/files/2026-08/example.apk",
  "release_notes": "修复已知问题\n优化连接稳定性",
  "is_published": false
}
```

`version_code` 是 Android 的内部版本号（Gradle `versionCode`），必须是正整数，且新增时必须大于数据库中已有的最大版本号。例如已有 `1` 和 `3` 时，新版本至少填 `4`。

创建时 `is_published` 可选：`false` 创建草稿，`true` 创建后立即发布并自动下架其他已发布版本。仅草稿可以编辑。下架当前版本后，客户端版本检查将得到 `data: null`，因此不应在正常发版流程中下架唯一发布版本。
