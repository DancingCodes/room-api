# Room 接口文档

## 通用规则

接口前缀：

```txt
/api/v1
```

服务端口固定为 `8080`。CORS 接受全部来源。

HTTP 响应统一格式：

```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

业务 code：

- `200` 成功
- `401` 鉴权失败
- `500` 错误

HTTP 状态码统一返回 `200`，WebSocket 鉴权失败返回 HTTP `401`。

鉴权请求头：

```txt
Authorization: Bearer jwt_token
```

参数规则：

- 字符长度按 Unicode 字符数计算
- 邮箱 trim 后转小写
- 昵称 trim 后 1-8 个字符
- 消息内容 trim 后 1-50 个字符

免登录接口：

- `POST /api/v1/auth/email-code`
- `POST /api/v1/auth/email-login`

## 通用对象

用户：

```json
{
  "id": 1,
  "email": "alex@example.com",
  "nickname": "Alex",
  "avatar_url": "https://api.dicebear.com/9.x/initials/png?seed=alex%40example.com&size=128",
  "current_room_id": 1,
  "created_at": "2026-06-16T16:00:00+08:00",
  "updated_at": "2026-06-16T16:00:00+08:00"
}
```

`current_room_id` 表示当前用户所在房间 ID，没有所在房间时为 `null`。该字段不在 `users` 表存储，接口返回时从 `room_members` 查询。

房间：

```json
{
  "id": 1,
  "name": "Alex 的房间",
  "owner_id": 1,
  "current_members": 1,
  "max_members": 8,
  "created_at": "2026-06-16T16:00:00+08:00"
}
```

房间成员：

```json
{
  "user_id": 1,
  "nickname": "Alex",
  "avatar_url": "https://api.dicebear.com/9.x/initials/png?seed=alex%40example.com&size=128",
  "is_owner": true,
  "mic_status": "off",
  "joined_at": "2026-06-16T16:00:00+08:00"
}
```

消息：

```json
{
  "id": 10,
  "room_id": 1,
  "sender_id": 1,
  "sender_nickname": "Alex",
  "sender_avatar_url": "https://api.dicebear.com/9.x/initials/png?seed=alex%40example.com&size=128",
  "type": "text",
  "content": "hello",
  "created_at": "2026-06-16T16:00:00+08:00"
}
```

## 认证

用户不再使用账号和密码。客户端只需要邮箱验证码登录；新邮箱会在登录接口中自动创建用户。

### 发送邮箱验证码

```txt
POST /api/v1/auth/email-code
```

请求：

```json
{
  "email": "alex@example.com"
}
```

响应：

```json
{
  "code": 200,
  "message": "成功",
  "data": null
}
```

### 邮箱验证码登录

```txt
POST /api/v1/auth/email-login
```

请求：

```json
{
  "email": "alex@example.com",
  "email_code": "123456"
}
```

说明：

- 如果邮箱已存在，校验验证码后直接登录。
- 如果邮箱不存在，校验验证码后自动创建用户，然后直接登录。
- 自动昵称来自邮箱 `@` 前面的部分，最多 8 个 Unicode 字符；重复时自动追加数字后缀。
- 自动头像 URL 使用邮箱作为 seed 生成。

响应：

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "token": "jwt_token",
    "user": {
      "id": 1,
      "email": "alex@example.com",
      "nickname": "alex",
      "avatar_url": "https://api.dicebear.com/9.x/initials/png?seed=alex%40example.com&size=128",
      "current_room_id": null,
      "created_at": "2026-06-16T16:00:00+08:00",
      "updated_at": "2026-06-16T16:00:00+08:00"
    }
  }
}
```

## 用户

### 当前用户

```txt
GET /api/v1/users/me
Authorization: Bearer jwt_token
```

响应：

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "user": {
      "id": 1,
      "email": "alex@example.com",
      "nickname": "alex",
      "avatar_url": "https://api.dicebear.com/9.x/initials/png?seed=alex%40example.com&size=128",
      "current_room_id": null,
      "created_at": "2026-06-16T16:00:00+08:00",
      "updated_at": "2026-06-16T16:00:00+08:00"
    }
  }
}
```

### 更新用户资料

```txt
PATCH /api/v1/users/me
Authorization: Bearer jwt_token
```

请求，`nickname` 和 `avatar_url` 至少传一个，可同时传：

```json
{
  "nickname": "Alex",
  "avatar_url": "https://example.com/avatar.png"
}
```

响应：同当前用户响应。

### 上传图片文件

```txt
POST /api/v1/uploads/image
Authorization: Bearer jwt_token
```

`multipart/form-data`：

```txt
file: 图片文件
```

响应 data：
```json
{
  "url": "https://example.com/avatar.png"
}
```

## 房间

### 房间列表

```txt
GET /api/v1/rooms?page=1&page_size=20
Authorization: Bearer jwt_token
```

### 创建房间

```txt
POST /api/v1/rooms
Authorization: Bearer jwt_token
```

请求：

```json
{
  "max_members": 8
}
```

响应 data：

```json
{
  "room": {
    "id": 1,
    "name": "Alex 的房间",
    "owner_id": 1,
    "current_members": 1,
    "max_members": 8,
    "created_at": "2026-06-16T16:00:00+08:00"
  },
  "members": [
    {
      "user_id": 1,
      "nickname": "Alex",
      "avatar_url": "https://api.dicebear.com/9.x/initials/png?seed=alex%40example.com&size=128",
      "is_owner": true,
      "mic_status": "off",
      "joined_at": "2026-06-16T16:00:00+08:00"
    }
  ]
}
```

### 房间详情

```txt
GET /api/v1/rooms/{room_id}
Authorization: Bearer jwt_token
```

响应 data：同创建房间。

### 进入房间

```txt
POST /api/v1/rooms/{room_id}/join
Authorization: Bearer jwt_token
```

响应 data：同创建房间。重复进入当前已经所在的同一房间时，后端会幂等返回房间详情，不重复广播 `member.joined`。

### 离开房间

```txt
POST /api/v1/rooms/{room_id}/leave
Authorization: Bearer jwt_token
```

### 更新麦克风状态

```txt
PATCH /api/v1/rooms/{room_id}/mic
Authorization: Bearer jwt_token
```

请求：

```json
{
  "mic_status": "on"
}
```

`mic_status` 可为 `on` 或 `off`。

## 消息

```txt
GET /api/v1/rooms/{room_id}/messages?limit=20&before_id=100
Authorization: Bearer jwt_token
```

### 发送消息

```txt
POST /api/v1/rooms/{room_id}/messages
Authorization: Bearer jwt_token
```

请求：

```json
{
  "content": "hello"
}
```

## WebSocket

```txt
GET /api/v1/ws/rooms/{room_id}
Authorization: Bearer jwt_token
```

事件：

- `member.joined`
- `member.left`
- `room.owner_changed`
- `message.created`
- `member.mic_updated`

统一格式：

```json
{
  "type": "event.name",
  "room_id": 1,
  "data": {}
}
```
